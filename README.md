# V's Venture — Static multi-page website

## Pages
- index.html — Home
- about.html — About Us
- investment-focus.html — Investment Focus
- portfolio.html — Portfolio
- founders.html — For Founders
- contact.html — Contact

## Run locally
Open `index.html` in a browser, or use a simple local server:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Before publishing
1. Replace `hello@vsventure.example` in `js/script.js` with the verified contact email.
2. Add approved company logo, address, phone and social links if available.
3. Add only verified portfolio companies and leadership biographies.
4. Confirm the investment thesis, geographic focus, ticket sizes and any legal disclosures.
5. Consider moving the contact form to a secure form service or backend if direct email composition is not desired.

The current portfolio page intentionally contains a placeholder rather than invented investments. No claims about past investments, returns, assets under management, or regulatory status have been added.
